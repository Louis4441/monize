Drop PNG screenshots here using the same file names as the Monize wiki,
e.g. dashboard-overview.png, transactions-list.png, reports-page.png.

The site tries this folder first and silently falls back to
https://raw.githubusercontent.com/wiki/kenlasko/monize/images/<name>.png
so it looks right even when this folder is empty.

Run scripts/fetch-screenshots.sh (macOS/Linux) or
scripts/fetch-screenshots.ps1 (Windows) to fill it automatically.
